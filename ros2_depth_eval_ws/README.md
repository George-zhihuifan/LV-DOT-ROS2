# ros2_depth_eval_ws

Minimal ROS2 Jazzy workspace for the depth-camera A/B validation plan.

Packages:
- `depth_eval_bringup`: launch files and simulation assets.
- `depth_eval_tools`: ROI depth evaluation and export scripts.

Current status:
- ROS2 Jazzy is present on this system.
- `ros-jazzy-ros-gz` and `ros-jazzy-ros-gz-sim` still need system-level install.
